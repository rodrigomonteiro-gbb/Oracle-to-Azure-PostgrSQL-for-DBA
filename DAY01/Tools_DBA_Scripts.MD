# DBA Scripts

</br>



| Script | Use case | Related workload |
| --- | --- | --- |
| [DBA_ActivityReview](../Scripts/troubleshooting/DBA_ActivityReview.sql) |  Reviews current PostgreSQL sessions, active queries, wait events, transaction age, query duration, and blocking PIDs. Useful for general real-time workload monitoring. | [Compile Workload](Workload_01_CompileWorkload.MD) |
| [DBA_BlockingReview](../Scripts/troubleshooting/DBA_BlockingReview.sql) | Diagnoses lock contention by identifying blocked sessions, blocking sessions, lock types, affected objects, blocking duration, and blocker query details. | [Blockers](Workload_04_Blockers.MD) |
| [DBA_ConnectionAnalysis](../Scripts/troubleshooting/DBA_ConnectionAnalysis.SQL) | Analyzes connection utilization, backend processes, session states, waits, connection capacity, and relevant memory settings. Designed primarily for the connection-test workload. | [Connection Test](Workload_00_Connection_Test.MD) |
| [DBA_CursorsReview](../Scripts/troubleshooting/DBA_CursorsReview.SQL) | Monitors cursor workloads through session activity, waits, locks, function statistics, statement performance, table access, index usage, and update-related table health. | [Cursors](Workload_07_Cursos.MD) |
| [DBA_EnableTracking](../Scripts/troubleshooting/DBA_EnableTracking.SQL) | Enables or disables PostgreSQL performance tracking settings, including I/O timing, nested statement tracking, and planning statistics. Requires elevated privileges or managed-service parameter configuration. | [Query Store Demo](Workload_00_QueryStoreDemo.MD) |
| [DBA_ErrorsReview](../Scripts/troubleshooting/DBA_ErrorsReview.sql) | Reviews the intentional-error workload, including active sessions, unhealthy transaction states, rollback statistics, SQLSTATE distributions, and individual events recorded in pgbench_error_log. | [Errors](Workload_08_Errors.MD) |
| [DBA_ExecutionPlan_Analysis](../Scripts/troubleshooting/DBA_ExecutionPlan_Analysis.sql) | Provides detailed performance analysis for the execution-plan workload, covering statement latency, planning time, I/O, cache efficiency, temporary spills, JIT, parallelism, WAL, waits, and object access. | [Execution Plan](Workload_06_Execution_Plan.MD) |
| [DBA_IndexAnalysis](../Scripts/troubleshooting/DBA_IndexAnalysis.sql) | Reviews index inventory, definitions, usage, I/O, duplication, validity, physical condition, cache residency, and hypothetical index opportunities. Includes optional `pgstattuple`, `pg_buffercache`, and HypoPG examples. | [Index Analysis](Workload_00_IndexAnalysis.MD) |
| [DBA_NonOptimal_Queries](../Scripts/troubleshooting/DBA_NonOptimal_Queries.sql) | Compares non-sargable and optimized queries using live activity, pg_stat_statements, table scan statistics, and index usage. Primarily supports the SARGability workload. | [Sargability Queries](Workload_05_Sargability_Queries.MD) |
| [DBA_StatisticsAnalysis](../Scripts/troubleshooting/DBA_StatisticsAnalysis.sql) | Reviews planner-statistics freshness, autoanalyze thresholds, column distributions and targets, extended statistics, partition coverage, active `ANALYZE`, and workload candidates. Includes reviewable statistics maintenance commands. | [Statistics Analysis](Workload_00_StatisticsAnalysis.MD) |
| [DBA_TempDBReview](../Scripts/troubleshooting/DBA_TempDBReview.sql) | Analyzes PostgreSQL temporary processing, including temporary tables, executor spills, session activity, blocking, source-table access, database temporary-file totals, and PostgreSQL 16+ I/O statistics. | [TempDB](Workload_09_TempDB.MD) |
| [DBA_VacuumAnalysis](../Scripts/troubleshooting/DBA_VacuumAnalysis.sql) | Analyzes VACUUM and autovacuum health, including configuration, maintenance priorities, wraparound risk, active progress, blockers, cleanup horizons, and table freeze age. Generates reviewable maintenance and tuning commands without executing them. | [Vacuum Analysis](Workload_00_VacuumAnalysis.MD) |
